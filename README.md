# VoiceType

**按住右 Option 说话，松开后把文字输入当前光标处。**

VoiceType 是 macOS 菜单栏语音输入工具，使用 Apple Speech 识别和本地规则整理文字。支持按住说、单击免提、实时字幕和 Esc 取消。首次打开会显示使用引导，带你完成授权、验证快捷键，并在练习框里成功听写一句话。

## 第一次使用

双击 `build/VoiceType.app`。首次启动会出现「VoiceType · 使用引导」，以后常驻屏幕右上角的波形图标，没有 Dock 图标。

引导有六步：

1. **欢迎**：了解操作和音频处理方式，此时不开麦。
2. **授权与语言**：逐项点击授权，选择识别语言。应用会自动刷新权限和监听状态，全部就绪后才能继续。
3. **验证快捷键**：独立按下并松开键盘**右侧 Option**。看到检测成功后继续；这一步不会录音。
4. **试着说一句**：点击练习框，按住右 Option 说一句话，再松开。也可单击开始免提，再单击结束。出现识别文字并确认成功插入后，核对内容，点击「这就是我说的，继续」。
5. **文字偏好**：分别选择是否删除孤立语气词、清理句首口头语。两项默认关闭，提供清理前后示例，继续或跳过不会替你开启。
6. **准备好了**：点击「完成，开始使用」，然后在备忘录或其他普通输入框中使用。

完成状态只在成功试用后点击完成时保存。点击「稍后设置」或关闭窗口不会假装完成；下次启动仍会显示引导。通过菜单「使用引导与试用…」可以随时重新练习。关闭窗口会取消尚未提交的练习会话，并清空窗口内的练习文本。

**练习必须来自真实听写。**手动输入文字、只有剪贴板结果、切换到别的应用或失败的识别，都不会解锁试用成功。练习框使用正常的录音、识别、清洗及插入链路。练习成功不代表每个第三方应用都具有相同的插入兼容性。

## 三项必要权限

| 权限 | 用途 | 未授权时怎么做 |
| --- | --- | --- |
| 麦克风 | 在听写期间采集声音 | 在引导中点击授权；拒绝过则进入「隐私与安全性 → 麦克风」 |
| 语音识别 | 使用 Apple Speech 生成字幕与文字 | 点击授权；拒绝过则进入「隐私与安全性 → 语音识别」 |
| 辅助功能 | 全局快捷键、活动会话 Esc 过滤、文字插入和模拟粘贴 | 打开「隐私与安全性 → 辅助功能」，开启 VoiceType；没有条目时点「+」选择当前应用 |

三项权限都必需，当前不单独申请输入监控。返回引导后约 1.5 秒自动刷新；也可点击「重新检查」「重新连接」。权限、监听、输入设备或识别服务未就绪时，界面会指出原因。

授权请求由用户点击按钮发起，不会启动后连续弹出多个请求，也不会在录音期间请求权限。启动、浏览引导和设置、练习快捷键、空闲等待时均不开麦。

## 日常操作

先点击目标输入框，把光标放在想输入的位置，关闭菜单，再操作快捷键。

| 操作 | 效果 |
| --- | --- |
| 按住右 Option 说话，松开 | 结束采集，识别并尝试插入文字 |
| 快速单击右 Option，再单击 | 第一次开始免提，第二次结束 |
| 免提中再次按住右 Option，松开 | 转为按住说，并在松开时结束 |
| 活动会话按 Esc | 取消尚未提交的听写；本次 Esc 按下、重复和配对松开不传给目标应用 |
| 菜单「取消当前听写」 | 另一种取消方式，HUD 本身点击穿透 |
| 菜单「使用引导与试用…」 | 重新检查授权并练习 |

本版默认固定右 Option，不支持自定义快捷键。左 Option 不启动听写；同时按其他修饰键不启动，按住右 Option 再组合普通键会取消。按住与单击的分界为 250ms，实际使用无需记时间：短句按住，长句单击免提。最长采集 5 分钟后自动结束。

HUD 显示录音、字幕、处理中及结果状态，不夺走输入框焦点。空闲时 Esc 保留原行为。已经提交的文字无法通过 Esc 撤回，请在目标应用中自行撤销。

## 文字清理与隐私

基础规则整理多余空格、部分重复标点等格式。两项可选规则独立保存，从下一次会话生效，可通过菜单「文字清理」随时关闭：

| 可选规则 | 示例 | 默认 |
| --- | --- | --- |
| 删除孤立语气词 | `呃，明天开会。` → `明天开会。` | 关闭 |
| 清理句首口头语 | `那个，明天开会。` → `明天开会。` | 关闭 |

规则范围保守，保留「嗯。」这样的回答、「那个方案」等指代，以及受保护的引用／代码。规则可能改变语气，因此不自动勾选。当前没有模型润色，不需要 API Key。

识别优先在设备内完成。如果某语言不支持端侧识别，可以改用支持的语言，或阅读说明后明确允许 Apple 服务器识别。**系统语音识别权限与同意上传音频是两件事。**未经同意不会自动切到服务器；打开隐私模式会强制端侧识别，无法端侧识别的语言会被阻止。

不保存录音文件或听写正文，不向 OpenRouter 发送音频或文本。练习文本只在窗口内存中保留。默认保存语言、清理偏好、服务器同意及引导完成状态；诊断和会话日志仅记录状态、错误类别和耗时。系统模型准备可能需要下载，服务器识别需要网络。

## 插入与剪贴板

正常交付顺序是 **辅助功能直接插入 → 剪贴板粘贴 → 仅复制**。确认文字真的写入后才报告插入成功。

- 直接插入成功时不改剪贴板。
- 粘贴前备份原剪贴板，发出 Cmd+V 后等 500ms，仅在版本未被改动时恢复原内容。你期间复制了别的内容则不恢复。
- 录音期间切换应用后，即使切回，也仅复制并提示手动 Command+V；这份结果不自动恢复成旧剪贴板。
- 「可能已经插入，请检查」表示无法确认结果，为避免重复文字不会再次自动粘贴。
- 检测到密码框或系统安全输入时阻止录音／插入，或停止当前会话。

## 常见问题

| 现象 | 下一步 |
| --- | --- |
| 打开后找不到窗口 | 查看右上角波形图标，点击「使用引导与试用…」 |
| 右 Option 没反应 | 检查权限和监听状态；空闲时重新连接，确认是右侧按键并检查改键软件 |
| 快捷键练习无法通过 | 将引导窗口置于前台，单独按下再松开右 Option；这一步不会录音 |
| 听写练习无法继续 | 点击练习框再说话；需真正识别并插入，手动打字或仅复制不算成功 |
| 没有识别到语音 | 检查系统声音输入设备、麦克风距离和语言，点击「清空并重试」 |
| 识别暂不可用 | 在授权页检查／更换语言和系统识别资源，等待服务可用；不会静默上传音频 |
| 安全输入暂停 | 离开密码框，检查其他应用的安全键盘输入开关 |
| 监听被停用 | 点击「重新连接」。超时可自动恢复，系统主动停用需要明确重连 |
| 已复制但没有输入 | 按 Command+V，复制不等同于已插入 |
| 升级后权限异常 | 先退出 App，重新打开；仍异常再在系统设置中重新启用当前应用的辅助功能权限 |

## 构建、测试与交付

项目采用 Swift 5.9 语言模式、SwiftUI + AppKit，部署目标 macOS 13+。当前构建环境为 Apple Silicon、macOS 27.0.1、Swift 6.4 Command Line Tools；尚未在 macOS 13 或 Intel 实机验收。

在仓库根目录运行：

```bash
./scripts/test.sh
./scripts/build-app.sh
open build/VoiceType.app
```

在禁止生成调试符号的受限环境中，可使用：

```bash
VOICETYPE_DEBUG_INFO_FORMAT=none ./scripts/build-app.sh
```

正常使用请通过 Finder 或 `open` 启动。更新时先退出旧实例，再打开新版本，不要同时运行两个目录里的 VoiceType。`build/VoiceType.app` 是构建产物，交付副本位于仓库旁的 `outputs/voicetype/VoiceType.app`。

无开发证书时使用 ad-hoc 签名，尽力保留本地重建的权限；这不是已公证的正式分发包。有开发证书时可设置 `CODESIGN_IDENTITY`。

测试覆盖会话状态机、模拟端到端、按键／Esc、清理选择、插入验证及引导成功条件。纯逻辑测试命令为 `./scripts/test.sh --filter VoiceTypeCoreTests`。系统适配器测试需要可访问 macOS 系统服务；沙箱中的剪贴板测试失败不能等同于产品功能失败，也不能据此声称完整测试通过。真实授权、麦克风及外部应用兼容性仍需实机验证。

## 日志与实现边界

菜单「打开延迟记录」进入 `~/Library/Application Support/VoiceType/`：

- `metrics.jsonl`：会话结果、识别／交付路径及延迟，不含正文。
- `diagnostics.json`：运行路径、权限、监听、右 Option 次数和最近错误，不含普通按键或正文。

早期三次中文端侧／AX 实测的停止到插入为 135、127、104ms，声音起点到首字为 644、528、675ms；样本不足以宣称稳定 p95 达标，首字 <500ms 仍是目标。

尚未实现：自定义快捷键、OpenRouter 润色、正文历史、日志自动清理、HUD 计时与临近上限提醒。大剪贴板可能造成卡顿；很慢的应用可能在 500ms 恢复后才消费粘贴内容。详细设计见 [design.md](design.md)，本轮实际验证与限制见 [PROGRESS.md](PROGRESS.md)。
